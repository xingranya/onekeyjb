# 一加16提权越狱 v2.5.35 更新日志（保留授权列表 + 资产缓存 + 轮询优化）

作者：星苒鸭 · github.com/xingranya · xran.uk

## 1. 保留管理器 root 授权列表

原因：加载器 cred.bin 在投放 ksud 前会执行 rm -rf /data/adb/ksu，把管理器的授权/配置一起清掉。

v2.5.35 已把这条命令改成不会命中真实目录的等价命令（rm -rf /data/adb/ksx），
不再删除 /data/adb/ksu；其余加密封装/投放逻辑不变。

## 2. 资产缓存

- 缓存目录：/data/local/tmp/onekey-cache-<versionCode>
- 首次运行仍从 APK 投放一次；之后用硬链接放进本次工作目录，不再重复推送约 20MB
- 管理器自带 ksud 用 SHA-256 判断是否需要更新缓存
- 链接失败会明确记录并回退，避免缓存文件缺失导致启动失败
- 删除该目录后会重新填充，不影响正确性

## 3. 轮询粒度优化

- 安全策略轮询：5 秒 → 1 秒
- 内核模块加载轮询：5 秒 → 1 秒
- 心跳仍每 30 秒输出，180 秒无心跳中断的看门狗不变
- 如果当前已经是 Permissive，直接跳过安全策略切换

## 4. 审查记录（本轮只改了这三项）

- cred.bin 只替换同长度字符串，其他字节未改；APK 内已校验为新字符串
- 缓存函数检查了：缓存命中/失效、硬链接与 cp 回退、链接失败日志、按管理器区分的 ksud 缓存
- 轮询改动只影响检测频率和心跳显示，未改 v36/writer 参数、未改漏洞原语
- 构建通过；但当前电脑没有连接手机，这一版还没有做真机回归
- 需要真机确认：连续越狱两次后管理器授权列表是否保留；第二次运行是否明显更快

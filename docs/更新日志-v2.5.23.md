# 一加16提权越狱 v2.5.23 更新日志（包体从 48MB 精简到 30.6MB）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 包体为什么涨到 50MB
v2.5.17 接入上游 loader2/w2 链时，为了保留回退能力，APK 里同时打进了两套完整资产：

- 上游链资产 `assets/core/`：4 个 ksud（约 22.2MB）+ 4 个 LKM + 5 个 exploit 二进制 + symbols
- v1.8 回退链资产 `assets/pyb110/`：又一份 4 个 ksud（与 core 里的**完全相同**，约 22.2MB）+ 4 个 LKM
- 另外还有旧链二进制/模板/syms（约 9MB）

两套 ksud 字节完全一致，属于纯重复，所以包体从 23.8MB 涨到了 48MB。

## v2.5.23 调整
- 删除 `assets/pyb110/ksud_*` 中重复的 4 个 ksud（约 22.2MB）
- 回退链的 ksud 改为复用 `assets/core/ksud_*`（字节相同，功能不变）
- APK：**48.1MB → 30.6MB**
- 越狱流程、su 授权、ColorOS 守卫处理、四管理器支持均不变

## 如果还想更小
还能再降到约 24MB：直接去掉 v1.8 回退链资产（约 6.5MB）和旧链二进制/模板（约 3MB）。
但会失去“上游链加载失败时回退 v1.8 链”的兜底能力，是否要做由你决定。

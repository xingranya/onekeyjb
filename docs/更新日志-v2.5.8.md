# 一加16提权越狱 v2.5.8 更新日志（代码审查修复）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 本版来源：外部模型代码审查（gpt-6.1-sol）后逐条修复
1. **管道退出码被掩盖**：`sh core.sh | tee` 只看 tee 的状态，脚本失败可能被当成成功
   - 现在引擎只认脚本输出的 `@EXIT`；缺失即失败，不再用管道退出码兜底
2. **命令拼接安全引用**：所有路径/包名/日志路径经单引号转义再拼进 shell
3. **root 收尾入口参数化**：不再把环境变量直接拼进 `su -c` 双引号里；改为生成固定 wrapper 脚本（/data/local/tmp/root_stage.sh），KSU 通道与 su 回退都用它
4. **marker 原子化 + 本次运行标识**：post 阶段先用临时文件写 `OK:<runId>` 再原子 rename；引擎运行前删除旧 marker，只认本次 runId，避免旧 OK 误判成功
5. **后台进程生命周期**：所有后台任务结束都 `kill + wait`，失败路径与退出 trap 统一回收；不再依赖宽泛 pkill 作为唯一清理手段
6. **CPU 采集自适应**：从 tracefs 实际 CPU 目录枚举，不再硬编码 0-7
7. **心跳更严格**：引擎只有收到 `@TICK` 才刷新看门狗；长等待都补了心跳
8. **post 阶段校验**：配套组件缺失直接失败；管理器包名为空时跳过重启并明确记录；su 自检严格判断 uid=0（仅提示，不阻塞应用域授权）
9. **失败诊断**：终态 marker 记录真实退出码，导出诊断可读

## 其他
- 收尾仍为 v1.8 稳定流程：**不重命名 /data/system/packages.list**，不创建任何 su 挂载
- ColorOS 17 安全模块清理 + 软重启修复保留
- 四管理器配对、隐藏环境默认不开 SU、COUI 界面与旧功能全部保留

# 一加16提权越狱 v2.4.8 更新日志

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 🐞 修复「LKM 版本不匹配 / 内嵌 LKM 有可用更新 / 应用还是没有 root」
- 根因：v2.4.6~v2.4.7 给 SukiSU 用了 PC 版加载器，`finit_module` 参数是 `allow_shell=1 bundled=1`
- 内核把模块当成 **内嵌（bundled）LKM**，于是：
  - 管理器显示「内嵌 LKM 有可用更新 / 版本不匹配」
  - bundled 模式下的 su 兼容/授权链路和自定义 LKM 不同 → 管理器授权了应用也拿不到 root
- 上游能用时的加载参数只有 `allow_shell=1`，管理器显示 **[自定义]**，没有这个提示
- v2.4.8：**4 个管理器统一改用 perf_cred_sukisu 加载（只传 allow_shell=1，不再传 bundled=1）**，与上游 loader2 完全一致

## 🩺 新增「导出设备诊断」
- 关于页新增按钮，一键采集：
  uname / SELinux / kernelsu 模块 / /system/bin/su / /data/adb/ksud / 挂载痕迹 /
  应用 UID 的 su 结果 / ksud debug info / feature list / manager list / dmesg 里 kernelsu 相关日志
- 越狱失败、死机重启后直接把导出的 TXT 发我，能精确定位

## ⚠️ 关于「刷入过程中死机重启」
- 这类崩溃发生在漏洞写入阶段（v36 / cred 竞态），不是安装包问题；不同批次机器概率不同
- v2.4.8 去掉了 bundled 参数，能减少一种内核异常路径
- 若频繁发生：刷前先在管理器中备份/关闭模块，插电、屏幕常亮、后台清空再试；崩溃后重启再试，不要连续重试

## 刷完正确状态
- 管理器：**[LKM] [自定义] [越狱模式]**，无「内嵌 LKM 更新」提示
- 日志：`LAYOUT_DONE → MODULE_LOADED → MANAGER_CONNECTED → unpriv_su=0`（shell 域可能仍拒，属正常）
- 在管理器里给应用授权后重新打开应用即可用 root

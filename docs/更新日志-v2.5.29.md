# 一加16提权越狱 v2.5.29 更新日志（修复后即可识别管理器）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 这次补上的关键步骤
late-load 加载 LKM 时，内核不会像正常开机那样自动执行 ksud 的
post-fs-data / services / boot-completed，所以管理器可能拿不到内核通道，
表现为首页「未安装」，即使 root 和 su 都正常。

## v2.5.29 修复
点「修复」时，收尾脚本会自动补跑：

1. `chmod 644 /data/system/packages.list`
2. `/data/adb/ksud post-fs-data`
3. `/data/adb/ksud services`
4. `/data/adb/ksud boot-completed`
5. 再重启管理器并检查连接

同时保留：
- SukiSU 用 `manager add` 登记
- 官方 / Next / BakaSU 用各自匹配的 ksud（优先管理器自带 libksud.so）
- `debug set-manager` 在 CONFIG_KSU_DEBUG 未开时只提示，不再报失败
- 打开管理器首页显示「工作中」即识别成功

## 注意
- **同一个内核**（管理器已匹配当前 LKM）：点「修复」即可识别，不需要重启
- **切换管理器**（例如从 SukiSU 换官方/Next）：不同管理器对应不同 LKM，必须先重启手机，
  再选目标管理器点「一键越狱」，修复无法跨内核替换

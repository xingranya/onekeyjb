## 二、PGP 加密提交步骤（邮件渠道）

```bash
# 1. 导入小米公钥（从 trust.mi.com 获取或使用下方 fingerprint 核验）
gpg --keyserver keys.openpgp.org --recv-keys DCC2896C
gpg --fingerprint DCC2896C
# 核验 fingerprint 是否为：
# EF25 EADF 40D1 98D1 2029 F0A9 B4A8 E8AA DCC2 896C

# 2. 加密报告
gpg --encrypt --armor -r DCC2896C report.txt

# 3. 发送加密后的 report.txt.asc 至 Security@Xiaomi.com
```

## 三、提交后流程（官方承诺）

| 阶段 | 说明 |
|---|---|
| 响应 | 48 小时内发送响应启动通知 |
| 验证 | 安全工程师验证有效性与可利用程度 |
| 评分 | 评定漏洞等级与贡献币；如有异议可在漏洞详情留言或通过官方渠道沟通 |
| 修复 | 按等级修复（严重 14 天 / 高 28 天 / 中 42 天 / 低 175 天） |
| 披露 | 确认后 180 天内发布安全建议（SA） |

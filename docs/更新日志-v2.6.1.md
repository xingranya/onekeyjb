# 一加16提权越狱 v2.6.1 更新日志（5 管理器自适应 + 临时文件治理 + 截屏/授权修复）

作者：星苒鸭 · github.com/xingranya · xran.uk

## 1. 自适应管理器（5 个固定版本）

首页最上方新增「自适应管理器」开关：
- 开启：扫描本机已安装的管理器，只列出识别到的固定版本，由你选择要用的那个
- 关闭：显示全部 5 个固定版本，仍需版本/签名匹配才能开始

固定版本：
- KernelSU 官方 v3.3.1（versionCode 32680）
- KernelSU-Next v3.4.2（versionCode 33355）
- SukiSU Ultra v4.2.1-r2（versionCode 41068）
- BakaSU v4.2.0-rc3（versionCode 35171）
- FinaSU v1.0.10（versionCode 33034，登记适配验证中，暂不可执行）

版本或签名不匹配会直接拒绝开始；不再「仅提示、继续加载」。
APatch 已从本工具删除：不检测、不显示、不支持（官方上限内核 6.12，本机 6.18 无模块）。

## 2. 临时文件治理

新增 TempJanitor：
- 每次开始前清理旧的 onekey 工作目录、ksud/LKM 副本、post/root 临时脚本
- 每次结束（成功/失败）清理本次目录与临时文件
- 缓存只保留当前版本的 onekey-cache-<versionCode>，旧版本缓存自动删除
- 日志超过 256KB 截断，避免长期累积
- 不再对整个 /data/local/tmp 做无差别删除

## 3. 截屏与安全组件

- 安全组件临时停用从「引擎一开始」移到加载前，缩短禁用窗口
- 兼容脚本 root_stage_v24.sh 中残留的 oplus_secure rmmod 已删除
- 软重启改为单路径：先 ksud soft-reboot，失败才 zygote，避免双重重启竞态
- 收尾恢复 exsystemservice / securityguard / safecenter，保持截屏和安全组件功能

## 4. 授权列表保护

- v2.5.35 已修正 cred.bin 不再删除 /data/adb/ksu
- 新增快照：收尾成功后备份管理器数据目录到 /data/adb/onekey-preserve（root-only，只留最近一份）
- 下一轮启动前若目录缺失，尝试恢复快照

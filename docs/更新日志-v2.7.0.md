# 一加16提权越狱 v2.7.0 更新公告

作者：星苒鸭 · github.com/xingranya · xran.uk

## 重点：真正的自适应管理器

- 首页开启「自适应管理器」后，不再要求你安装固定版本
- 自动扫描手机里已安装的管理器，按签名识别，随机包名也能认
- 直接读取你当前安装的管理器 APK，提取配套内核组件和 root 组件
- 管理器更新后，重新点准备/越狱即可重新适配，不需要等工具更新
- 已实测：最新 SukiSU Ultra 4.2.1-r2（随机包名）完整越狱成功，管理器显示「工作中」，超级用户和模块列表保留

## 管理器支持

- 官方 KernelSU
- KernelSU-Next
- SukiSU Ultra
- BakaSU
- FinaSU（自适应模式已开启，固定模式需开启自适应）
- APatch 已移除，不再支持

## 修复与优化

- 修复越狱后管理器显示「未安装」
- 修复每次越狱后管理器授权列表被清空
- 修复越狱后截屏不可用
- 修复安全组件被长时间禁用、软重启异常
- 修复打开 App 偶发崩溃
- 修复临时文件越积越多，运行结束自动清理
- 越狱期间增加前台保活和唤醒锁，切后台/熄屏更稳
- 授权数据增加本地快照，异常后可恢复
- 旧 SukiSU 40994 和新随机包名 41068 同时安装时会选择新版本

## 注意事项

- 自适应模式仍是 Beta：FinaSU 的 dynamic 登记已写入代码，但还没有真机跑完整流程；官方 / Next / BakaSU 也在逐个验证
- 不开自适应时仍只支持固定版本；想用最新版管理器请开启自适应
- 重启后 root 会失效，需要重新越狱
- 如果管理器更新后识别异常，先点「准备自适应适配」再越狱，并把日志发我

# 一加16提权越狱 v2.4.7 更新日志

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 🐞 修复「bl_*.bin 全空 / 反推 KASLR 失败 / 按多少次都一样」
- 现象：grab 阶段打印了文件大小、GRAB_DONE，但引擎判定 bl_0~7.bin 全部“为空/不存在”，提示没有可用 raw 抓包
- 原因：`grab.sh` 里写死了 `D=/data/local/tmp/onekey`，v2.4.3 改成唯一工作目录 `/data/local/tmp/onekey-<时间戳>` 后，
  抓包文件全被写到旧目录，引擎在本次目录找不到 → 每次都在这一步失败
- 修复：
  - `grab.sh` 改为通过 `/data/local/tmp/onekey_dir` 读取本次工作目录（perfetto 配置路径同步）
  - 引擎检查 bl 文件大小时改用 shell 的 `wc -c`（不再依赖应用进程 File API，避免 SELinux/权限误判）

## 传承 v2.4.6 的修复
- 投放前先创建唯一工作目录（修 su_forward.tmp: No such file or directory）
- 4 个 LKM 全部补全本机 vermagic（修 finit_module EINVAL / 模块根本没加载）
- SukiSU 改用 perf_cred（allow_shell=1 bundled=1）
- 收尾 su -c 优先、ksu_grant 兜底

# 一加16提权越狱 v2.5.24 更新日志（修复 KernelSU 官方管理器显示“未安装”）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 问题
v2.5.23 在 KernelSU 官方管理器用户上出现：
- 内核模块已经 Live（日志里 version 32680、lkm true）
- 但管理器首页显示「未安装 / 点击安装」
- 越狱日志里只有「管理器暂未连接」

## 原因
收尾脚本登记管理器时依赖：
`ksud debug get-sign <manager.apk>` 解析出证书 size/hash
如果输出格式不匹配或解析失败，脚本会**静默跳过登记**，导致管理器无法取得内核通道 → 显示未安装。

## v2.5.24 修复
1. App 端直接用 PackageManager 读取管理器 APK 的签名证书：
   - cert size = 证书 DER 字节长度
   - hash = 证书 SHA-256
2. 通过 ONEKEY_MGR_SIZE / ONEKEY_MGR_HASH 传给收尾脚本，不再依赖 debug get-sign 解析
3. 登记失败会明确输出警告，不再静默
4. 管理器首次未连接时自动重试一次登记 + 重启管理器
5. 保留 debug get-sign 作为兜底

## 验证方法
用 KernelSU 官方管理器：
1. 装 v2.5.24，点「修复」（内核已加载时只修复用户态）
2. 管理器应该不再显示「未安装」，能看到内核版本/模块状态
3. 若仍为未安装，请导出日志，重点看「管理器身份已登记 / 登记失败」那一行

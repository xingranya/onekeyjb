# 一加16提权越狱 v2.4.6 更新日志（两个关键修复）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 🐞 修复「投放失败 … su_forward.tmp: No such file or directory」（所有用户卡住的问题）
- 原因：v2.4.3 改成唯一工作目录后，投放组件前没有先创建该目录；旧投放函数只会 mkdir 固定的 /data/local/tmp/onekey
- 修复：投放前先建本次目录；投放函数改为按目标父目录自动创建

## 🐞 修复模块加载失败（这才是「刷了没 root / 没 su」的根因）
- 反汇编确认加载器 finit_module 的 flags=0，**不忽略 vermagic**
- 上游 3 个 LKM（Next/BakaSU/SukiSU）的 .modinfo vermagic 是短串 `6.18.21-4k`，设备要求完整串
  `6.18.21-android17-5-gf957accaf563-ab15926176-4k SMP preempt mod_unload modversions aarch64`
  → 内核直接返回 EINVAL，模块根本没加载
- 已按官方 LKM 相同方式处理：把 .modinfo 搬到文件末尾并写入完整本机 vermagic，**4 个 LKM 现在全部匹配**
- 官方 LKM 原本就是这种「末尾追加 .modinfo」的补丁形态，现在四个一致

## 🔧 与上游对齐的两处
- SukiSU 改用 perf_cred 加载器（参数 `allow_shell=1 bundled=1`，引导 ksud 放 /data/local/tmp/ksud342）；上游能用时 debug info 正是 bundled:true
- 收尾执行顺序：`su -c` 优先，ksu_grant 兜底（上游同款）

## 保留
- 唯一工作目录 / 旧 root 属主目录改名重建 / 自动清理
- su_compat 显式开启、管理器连接校验、未授权 su 自检
- 默认 SU 兼容开关（会暴露环境，默认关闭）

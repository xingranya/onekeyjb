# 一加16提权越狱 v2.7.2 更新公告（FinaSU 登记修复）

作者：星苒鸭 · github.com/xingranya · xran.uk

## 修复 FinaSU 管理器登记失败

v2.7.1 日志确认：
- 内置 FinaSU 兼容组件能正常加载
- 但管理器 UID 没取到，导致 dynamic grant 没有执行，登记失败

v2.7.2 处理：

- 优先使用 FinaSU 官方的“一步登记”命令：按 UID 自动提取签名、登记并授权
- UID 获取增加多重兜底：
  1. /data/user/0/<包名> 目录所有者
  2. /data/data/<包名>
  3. pm list packages -U
  4. cmd package list packages -U
  5. dumpsys package userId
- 一步登记失败时，再回退到 set-hash + grant
- 仍然失败会在日志里输出 UID、包名、stat 和 pm 查询结果，方便继续定位

## 注意

- FinaSU 仍属于修复测试版，真机登记需要你更新后验证
- 内置兼容组件按 FinaSU v1.0.10 准备；改包/其他版本可能不兼容
- 其他管理器继续按自适应流程逐个验证

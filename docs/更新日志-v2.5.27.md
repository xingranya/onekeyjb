# 一加16提权越狱 v2.5.27 更新日志（KernelSU-Next 管理器未安装修复）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 根因
KernelSU-Next 管理器 v3.4.2 的版本号是 **33355**；
但我们之前打包的 Next LKM（来自上游仓库，350,000B）里 **没有 33355 版本标记**，
管理器读不到匹配的内核版本，就显示「未安装 / 点击安装」。
（官方 KernelSU v3.3.1 的 LKM 里带 32680，BakaSU 的 LKM 也匹配，所以它们正常。）

## v2.5.27 修复
- 把 Next LKM 换成与 **v3.4.2 (33355)** 匹配的构建（473,953B）
- 校验结果：
  - 内含版本标记 33355
  - 内嵌管理器证书 SHA-256 为 79e590113c4c4c0c222978e413a5faa801666957b1212a328e46c00c69821bf7，
    与 KernelSU_Next_v3.4.2_33355-release.apk 的签名证书一致
- 加载/收尾逻辑不变，只替换 Next 的 ko

## 验证步骤（Next 用户）
1. 先重启一次手机（卸载当前已加载的旧 Next LKM；切换内核必须重启）
2. 安装 v2.5.27，选 KernelSU-Next，点一键越狱
3. 完成后打开 KernelSU-Next 管理器，应显示「工作中」而不是「未安装」
4. 如果仍显示未安装，请把日志里 `ksud debug info` 的内容发我

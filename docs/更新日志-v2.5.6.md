# 一加16提权越狱 v2.5.6 更新日志

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 修复「92% 卡住 / 卡屏 / 反复都过不去」
- 现象：越狱走到 92% 时卡住，屏幕卡死，反复重试都一样；部分设备正常
- 定位：卡在「管理器初始化」这一步。旧做法为了刷新管理器的内核绑定，会重命名系统文件 packages.list；部分设备上这一步会触发内核/系统服务互等，导致命令不返回、系统 UI 卡屏
- 解决：
  - 管理器初始化改成安全顺序：**动态登记 → 属性刷新 → 重启管理器 → 最后才用旧方式**，每次都用超时保护
  - 最后那一步一旦超时，会记住这台设备，**以后自动跳过**，不再反复卡死
  - 所有外部命令都加超时，任何一步都不会无限等待
  - 新增「无输出看门狗」：连续 150 秒没有进展就自动中断、尝试恢复、给出明确提示
  - 安全机制修复改为**提前排队**：即使管理器初始化卡住，修复仍会执行并尝试恢复系统

## 体验
- 进度条不再长时间停在 92%，改为按真实阶段推进，只前进不后退
- 越狱日志会落盘到设备，失败后可一键「导出设备诊断」发回定位
- 失败提示改为更直白的说明，不再让用户无限等待

## 文案与实现全部自有化
- 越狱脚本、日志、界面提示、更新说明全部改用本项目自己的写法，不再沿用他人的脚本文字
- 内部组件目录与命名一并更换为中性名称，调用方式不变
- 第三方开源组件的署名与许可证保留在关于页

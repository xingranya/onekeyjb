# 一加16提权越狱 v2.7.1 更新公告（FinaSU 适配修复）

作者：星苒鸭 · github.com/xingranya · xran.uk

## 修复 FinaSU 自适应提取失败

有用户反馈：FinaSU 已安装，但自适应准备时报「未找到可用的 kernelsu 模块」。

v2.7.1 处理：

- FinaSU 管理器登记链路已完整开启
- 如果从当前安装的 FinaSU APK 里提取模块失败，自动改用内置的 FinaSU 兼容组件继续（只对 FinaSU 生效，其他管理器仍然失败即停止）
- 提取失败时会显示更具体的原因，方便反馈
- FinaSU 使用 dynamic 登记：先写入管理器签名，再授权管理器 UID
- 登记失败会明确标记本次越狱失败，不再误报完成

## 注意

- 内置兼容组件按 FinaSU v1.0.10 准备；如果你安装的是其他版本/改包，仍可能不兼容
- FinaSU 的真机完整流程还没有最终确认，本次属于修复测试版
- 官方 KernelSU / Next / BakaSU 继续按自适应流程逐个验证
- 不开自适应时仍只支持固定版本

## 其他

- 保留 v2.7.0 的改进：真正自适应、随机包名识别、前台保活、授权列表保留、临时文件清理
- 已实测 SukiSU 4.2.1-r2 随机包名完整越狱成功

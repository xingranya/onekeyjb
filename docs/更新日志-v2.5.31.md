# 一加16提权越狱 v2.5.31 更新日志（撤掉会卡住的 ksud 初始化调用）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## v2.5.29 SukiSU 失败的原因
v2.5.29 在收尾里补跑了：
- `ksud post-fs-data`
- `ksud services`
- `ksud boot-completed`

其中 `services` / `boot-completed` 是常驻/长流程命令，不会正常返回；
虽然加了 timeout，但连续等待把收尾阶段拖到超时，post 标记失败，SukiSU 也因此失败。
这是我们的改动引入的回归。

## v2.5.31 修复
1. **删除** post-fs-data / services / boot-completed 的自动调用
2. SukiSU 恢复走 `ksud manager add` 登记（v2.5.22 已真机验证正常的路径）
3. 官方 / Next / BakaSU 改为：
   - `pm install-existing --user 0 <管理器包名>`（安全刷新包状态）
   - `chmod 644 /data/system/packages.list`
   - `ksud debug set-manager`（CONFIG_KSU_DEBUG 未开时只提示）
   - 全程**不重命名 packages.list**，避免 92% 卡死回归
4. 保留诊断日志：
   - `ksud install rc=...`
   - `manager cert: size=... hash=...`
   - `ksud debug info: ...`

# 一加16提权越狱 v2.5.4 更新日志（P0 降检测）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## P0：App 内可做的降检测（不改变 root 授权链路）
1. **清理旧挂载**
   - 卸掉所有历史 `su_compat` / `onekey-su` overlay 挂载（v2.4.x 默认 SU 时代残留，升级不重启会一直挂着 → 检测里的「挂载异常(1)」）
   - 删除 `/data/adb/onekey-su*` 旧兼容层目录
2. **清理 /data/local/tmp 残留**
   - 越狱前 + 修复脚本内双重清理：`onekey*`、`ksu-op3.ko`、`ksud342`、`ksu_grant`、`root_stage.sh`、`onekey_dir`、`onekey_mgr_apk/pkg`、`su_repair*.log` 等
   - 修复目录 `/data/local/tmp/onekey_repair` 在修复成功后自删；失败才保留供诊断
3. **恢复 SELinux Enforcing**
   - 修复脚本收尾执行 `setenforce 1` 并记录 `getenforce`（漏洞链先切 Permissive 的痕迹不再留着）
4. **开启内核隐藏特性**
   - `ksud feature set selinux_hide 1`
   - `ksud feature set kernel_umount 1`
   （两个特性当前 4 个 LKM 都支持；能降低 SELinux Policy 与部分挂载类检测）

## 顺带修复
- su 修复脚本改放独立目录 `/data/local/tmp/onekey_repair`，不再受越狱工作目录清理影响（v2.5.3 的修复排队可能因目录被清而失效）

## 仍然无法在 App 内解决的（保持原状）
- 「设备取得 ROOT 权限/异常模块」「Found ksu」：LKM 无 susfs，/proc/modules 里就是 kernelsu + /data/adb/ksu 痕迹 → 需要带 SUSFS 的 LKM（P2）
- Magic Mount / Mount loophole / 隐藏应用列表：来自已安装模块（P1，需要用户逐个停用排查）

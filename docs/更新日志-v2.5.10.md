# 一加16提权越狱 v2.5.10 更新日志（实时进度与日志）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 为什么之前“像卡住了”
v2.5.9 及之前，为了减少刷屏，引擎把心跳（@TICK）和底层进度过滤掉了，
只在阶段切换时写一条日志：
- 采集约 60 秒、等待安全策略、定位凭证、加载内核模块、初始化管理器这些长步骤期间，日志会沉默 30 秒~数分钟
- 进度条也只在阶段切换时跳一下，容易让人以为程序不动了

## v2.5.10 修复
- **心跳全部显示**：
  - 采集内核事件 N/300（每约 5 秒更新）
  - 等待安全策略切换 XXs
  - 正在定位内核凭证 XXs
  - 正在加载内核模块 XXs
  - 安装配套组件 / 登记管理器 / 重启管理器
- **底层活动实时透出**：每 8 秒至少输出一条当前进展（attempt / LAND / FINIT / CAPS_READY / TWO_PHASE 等），能直观看到程序在动
- **进度条按心跳细分推进**：不再长时间停在 92%，阶段内也有连续变化
- **阶段开始提示预期上限**：例如“正在校准内核地址（最多约 2 分钟）”
- 仍然：启动后自动跳日志页、已用时间持续计时；真卡死会在 180 秒无心跳时中断并提示卡在哪一步

## 使用
打开 App → 选管理器 → 一键越狱，日志页会持续滚动显示实时进度；
如果某一行超过 3 分钟没有任何新日志，把日志或「导出设备诊断」发我。

# 一加16提权越狱 v2.5.26 更新日志（修正管理器状态误报）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 现象
v2.5.25 在 BakaSU 上：
- 管理器首页明明显示「工作中 [LKM] [越狱模式]」
- 但越狱日志写着「debug set-manager 失败」和「管理器未连接内核」

## 原因
1. `debug set-manager` 需要内核开启 CONFIG_KSU_DEBUG；正式 LKM 没开，所以该命令必然返回
   `CONFIG_KSU_DEBUG is not enabled`。官方 / Next / BakaSU 本来就不靠它登记，管理器由
   `ksud install` 自动识别。这条不应显示成“失败”。
2. 日志里的「管理器未连接内核」是我们在管理器刚重启、fd 还没建立时就去探测，属于检测太早；
   管理器稍后打开时已经正常连接（首页显示工作中）。

## v2.5.26 调整
- `CONFIG_KSU_DEBUG is not enabled` 改为普通提示：「管理器由 ksud install 自动识别属正常」
- 管理器连接检测延长到最多 10 秒
- 最终提示改为：「管理器已启动；若首页显示工作中即正常，未显示请点修复重试」
- 不再把正常状态误报为失败

## 说明
BakaSU 显示的「0 个超级用户, 0 个模块」只是因为该管理器里还没授权应用，不代表 root 不可用；
su 通道自检已通过，在 BakaSU 里给目标应用授权即可。

# 一加16提权越狱 v2.6.2 热修复（CODE REVIEW 修复）

作者：星苒鸭 · github.com/xingranya · xran.uk

## 修复
- 修复打开 App 时可能崩溃：管理器证书表在 init 之后才初始化，扫描已安装管理器会访问空引用；已移到 init 之前。
- 恢复加载窗口的 ColorOS 安全组件临时停用：上一版移除 post-load 旧代码时误删了 core.sh 中加载前的保护分支，现已恢复。
- 启动时不再自动执行 TempJanitor，避免刷新/重建 Activity 时误删正在运行的任务目录和共享临时文件；清理只在本次运行开始与结束执行。

## 尚未完成（重要）
- 本版的自适应开关仍然只是“扫描已安装 + 固定版本校验”，不是你要的“读取用户管理器 APK、按文档提取并适配”的真正自适应。
- 真正运行时适配需要：shell 读取已装 APK → 裁出内嵌 6.18 模块/ksud → 生成并校验 adapter → 动态登记。该链路尚未实现，当前仍用内置模块。
- FinaSU 仍是验证中，不可执行。

# 一加16提权越狱 v2.5.11 更新日志（加载阶段回退 v1.8 链路）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 为什么又改
群友实测 v2.5.10 的日志停在「正在加载内核模块 60s」，随后整机卡死，只能强制重启。
v2.5.7 只回退了「收尾」，**加载阶段仍然是上游 loader2/w2 链路**；这次卡死就发生在 w2 写凭证/加载模块阶段。

## v2.5.11 改动
- 加载阶段回退到 v1.8 / v2.4 系列验证过的链路：
  1. v36 切换 SELinux Permissive
  2. perf_cred 选择可用的 cred
  3. v42 写入 cap_effective 并通过 finit_module 加载内核模块
- 配套内核仍使用本机 6.18.21 自编、已补全 vermagic 的四个 LKM（官方 / Next / BakaSU / SukiSU）
- 收尾仍是 v1.8 稳定流程：不重命名 /data/system/packages.list，通过 root 通道安装配套组件、动态登记管理器、重启管理器、su 自检
- 软重启修复、实时日志、导出诊断、四管理器、默认不开 SU、COUI 界面全部保留

## 预期
- 加载阶段日志会显示 perf_cred 候选、v42 阶段（TWO_PHASE / LAND / CAPS_READY 等），不再静默
- 加载成功后进入管理器初始化，最后可在管理器授权应用并调用 su

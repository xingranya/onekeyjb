**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 🐞 修复「投放失败：Permission denied，刷不了」
- 现象：修复/越狱时报 `sh: can't create /data/local/tmp/onekey/ksu_grant.tmp: Permission denied`
- 原因：上一次运行后 `/data/local/tmp/onekey` 残留成 root 属主/不可写，下一次 shell 投放时没有写权限；有人手机没有历史残留所以能正常刷
- 修复：
  - 每次运行改用**全新唯一工作目录** `/data/local/tmp/onekey-<时间戳>`，彻底避免历史目录污染
  - `ksu_grant`、`root_stage.sh`、`onekey_dir` 改放到 /data/local/tmp 固定可写位置
  - root 收尾脚本以 root 自动清理旧的 `/data/local/tmp/onekey` 遗留给后续 shell 使用
  - 失败也不会影响下一次运行

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 🐞 修复「刷完无法给软件授权 root / su 用不了」
- 原因：换用上游 6.18.21 自编 LKM 后，收尾脚本缺少两个关键步骤：
  1) 没有显式开启内核 su 兼容（su_compat），部分 LKM 默认不开 → 应用调 su 直接被拒
  2) 管理器加冕后没有验证它是否真正连上内核 → 管理器写不进授权，应用永远拿不到 root
- 修复：
  - 收尾阶段显式执行 `ksud feature set su_compat 1`，并输出 feature list 确认 ENABLED
  - 加冕 → 重启管理器 → 检查管理器是否取得内核连接（/proc/pid/fd 的 ksu 句柄）
  - 未连接则自动 `ksud manager add + set-enabled` 再重启一次（双保险）
  - 输出 manager list，可直接看到登记状态
  - 新增「未授权 su 自检」：setpriv 降到 uid 2000 执行 su，日志里看 `unpriv_su=0` 即内核放行
  - 越狱结束再补一条「原生 su 已放行 / 未放行」日志，出问题一眼定位

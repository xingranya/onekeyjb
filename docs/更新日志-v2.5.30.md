# 一加16提权越狱 v2.5.30（管理器识别诊断增强）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 背景
v2.5.29 的日志显示：
- 内核驱动 version 32680（与官方 KernelSU 管理器 v3.3.1 32680 匹配）
- ksud post-fs-data rc=0
- 但管理器仍显示未安装

需要确认两件事：
1. 收尾里的 ksud install 是否真的成功
2. 管理器 APK 的签名证书是否与内核内嵌的官方证书一致

## v2.5.30 增加
- 日志输出 ksud install 的返回码和完整输出
- 日志输出管理器证书：size 和 SHA-256
- 保留 post-fs-data/services/boot-completed 补跑

## 官方 KernelSU v3.3.1 的内置证书（用于对比）
- SHA-256：`c371061b19d8c7d7d6133c6a9bafe198fa944e50c1b31c9d8daa8d7f1fc2d2d6`
- 如果日志里 `manager cert: ... hash=...` 与上面不一致，
  说明装的管理器不是官方签名（被改包/第三方重签），内核不会识别它，
  必须换回官方 KernelSU APK 才能连接。

## 需要用户反馈的日志
- `ksud install rc=...`
- `manager cert: size=... hash=...`
- `ksud post-fs-data rc=...` / `ksud services rc=...`

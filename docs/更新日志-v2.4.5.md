# 一加16提权越狱 v2.4.5 更新日志（关键修复）

**作者：星苒鸭 · github.com/xingranya · xran.uk**

## 🎯 为什么刷了还是没 root / 没 su —— 已定位并修复
v2.4.2 换上游 LKM 时，我把「引导 ksud 的固定路径」改错了：

| 漏洞加载器 | 它硬编码读取的路径 |
| --- | --- |
| perf_cred（Next / 官方 / BakaSU 用） | `/data/local/tmp/ksud342` |
| perf_cred_sukisu（SukiSU 用） | `/data/local/tmp/onekey/ksud_sukisu` |

v2.4.2~v2.4.4 却把 ksud 投到了 `/data/local/tmp/ksud_next`、`/data/local/tmp/ksud_official` 等新路径，
导致 cred 阶段复制 ksud 到 /data/adb 布局时找不到文件 → `LAYOUT_DONE` 不出现 → **内核模块根本不会加载**
→ 后续管理器加冕、su_compat 全部无从谈起（表现就是“刷完了但没 root、没 su”）。

## v2.4.5 修复
- 恢复两个硬编码路径：`/data/local/tmp/ksud342` 和 `/data/local/tmp/onekey/ksud_sukisu`
- 每次越狱前保证固定目录可写（旧版残留的 root 属主目录会被改名后重建）
- 保留 v2.4.4 的 su_compat 显式开启、管理器连接校验、未授权 su 自检
- 保留 v2.4.3 的唯一工作目录与自动清理

## 验证方式（刷完后看日志）
- `LAYOUT_DONE` → `MODULE_LOADED` → `MANAGER_CONNECTED` → `unpriv_su=0`
- 管理器授权后，Root 诊断应 4/4

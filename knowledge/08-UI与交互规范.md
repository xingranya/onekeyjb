# 08 · UI 与交互规范

技术栈：Jetpack Compose + COUI（`io.github.suqi8.coui.kmp`），色板走 Monet 动态取色，默认主题粉 `#FFC0CB`。

## 页面结构

```
Scaffold(contentWindowInsets = 0)          // 避免二次 inset 叠加
├─ 状态栏遮罩（背景色实心，防 edge-to-edge 内容穿透）
├─ TopBar（固定，高 54dp + 版本行）
│    ├─ 标题 + 当前页图标
│    └─ "v2.17.16 · #164"   ← 所有页面左上角常驻，10sp，主色
├─ AnimatedContent（4 个 Tab，淡入淡出 200ms）
│    ├─ 0 首页：越狱方式、管理器、环境、维护、诊断
│    ├─ 1 日志：实时日志、复制、导出、清空
│    ├─ 2 历史：运行记录、详情（含复制/导出）
│    └─ 3 关于：主题、更新、开源组件、声明
└─ AppBottomBar（自绘玻璃栏，70dp，图标 + 文字，毛玻璃背景）
```

内容区 padding：左右 16dp，top = 状态栏高 + 92dp，bottom = 导航栏高 + 92dp（给顶栏与底栏留位）。

## 顶栏版本号（硬性要求）

每个页面左上角都必须能看到 `v<versionName> · #<versionCode>`，来源是 `BuildConfig`，不写死：

```kotlin
Text(
    "v" + BuildConfig.VERSION_NAME + " · #" + BuildConfig.VERSION_CODE,
    fontSize = 10.sp,
    color = COUITheme.colorScheme.primary
)
```

目的：用户截图反馈时能一眼确认版本，避免"你用的是哪个版本"的来回。

## 组件规范

| 组件 | 规格 |
| --- | --- |
| 弹窗 | `WindowDialog(title, show, onDismissRequest)`，内容 Column 内边距 `horizontal = 4.dp` |
| 弹窗按钮 | 自绘 `DialogActions`：高 46dp、圆角 14dp、左右 8dp 内缩、两个按钮等分 |
| 列表项 | `BasicComponent(title, summary, startAction, endAction)` |
| 开关项 | `BasicComponent` + `Switch`，切换即生效并写日志 |
| 卡片 | `Card { Column(Modifier.padding(4.dp)) { … } } ` |
| 进度 | `LinearProgressIndicator(progress = pct / 100f)` |
| 版本卡片 | 12dp 圆角 + `surfaceContainer` 背景，点开显示 `notes[]`，展开用 `AnimatedVisibility(expandVertically)` |

颜色只用语义 token：`background`、`surfaceContainer`、`primary`、`onSurface`、`onSurfaceContainerVariant`、`error`、`onError`、`onPrimary`。

## 文案基调

- 陈述事实，不喊口号："98260 全链完成；重启后需要重新越狱。"
- 失败要说清下一步："98260 未完成；内核可能处于脏状态，重试前必须先硬重启设备。"
- 不写"可能/大概"当结论；不确定就标明条件（"需实测确认"）。
- 数值一律带单位：`40.85 MB`、`2.41 MB/s`、`剩余 23.15 MB`。

## 关键交互

| 场景 | 行为 |
| --- | --- |
| 点「一键越狱」（98260） | 先弹"运行前确认"，说明一次开机只能用一次、失败需硬重启，确认后才执行 |
| 点「一键越狱」（64560） | 直接执行并切到日志页 |
| 越狱成功后（98260） | 弹"越狱完成"，提示重启后需重新越狱 |
| 运行中 | 顶栏与底栏不隐藏，但所有会改状态的开关/选择被禁用 |
| 检查更新 | 有新版自动弹窗；下载中禁用两个按钮 |
| 历史详情 | 复制全文、导出 TXT（`CreateDocument`） |

## 无障碍与细节

- 图标都带 `contentDescription = null`（装饰性），可点击区域用文案承担语义；
- 触感统一 `rememberCouiHaptic()`，切换类交互用 `CouiHapticEffect.Switch`；
- 长文本 `maxLines` + `TextOverflow.Ellipsis`，日志用等宽字体并保留滚动位置；
- 弹窗内容超过屏幕时内部 `verticalScroll` + `heightIn(max = 240.dp)`，不撑破弹窗。

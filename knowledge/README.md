## AI 知识库

`ai-kb/` 下是本知识库的机器可读版本，供 AI 助手导入：

| 文件 | 格式 | 用途 |
| --- | --- | --- |
| `ai-kb/onekey-kb.json` | `paragraphs` | 段落式检索（一问一答/一段一主题） |
| `ai-kb/onekey-kb.docs.json` | `docs` | 整篇文档式注入（保留章节结构） |
| `ai-kb/build_kb.py` | 脚本 | 由 `knowledge/*.md` 重新生成上面两个 JSON |

改完 Markdown 后跑一次 `python3 knowledge/ai-kb/build_kb.py` 即可同步，避免两套内容漂移。

## 维护约定

- 版本号、versionCode、证书指纹、模块体积这类会变的数字，以 `merged-app/app/build.gradle.kts`、
  `JailbreakController.kt`、`cloud-catalog.json` 为准，改代码时同步改本文档。
- 不写"大概""可能"的结论；不确定就写清验证条件（例如"需装机确认"）。
